# Lx Search

Formulary lookup for coverage, price, prescribing authority and covered equivalents of a medication. Results filter by availability (all, paid, free), sort by relevance, name or price, show as cards or a table, and can be pinned, compared and exported to CSV.

## Limits

- The list is marked experimental in the app and may not be comprehensive.

## Network and install

Installable (PWA); works offline after the first load. Loads Google Fonts from a CDN.
